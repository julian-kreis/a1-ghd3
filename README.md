My project is a simple, interactive UFO flying through space animation.

![Screenshot](project_screenshot.png)

Design:
Uses multiple colorful shapes to create the UFO.
The varying star sizes and speed create a nice, dynamic space background.
The ugly, default mouse cursor is removed for a sci-themed green reticle.

Technical:
The speed and size of the UFO and starts is scaled based on the starting size of the window.
The UFO moves to follow the mouse cursor.
The objects in the animation move at a constant speed regardless of framerate.
Uses multiple shapes including circle, ellipse, polygon, rect, and line

References:
Copied starter code from
https://d3js.org/getting-started

AI Usage:
Used AI to provide examples of how to draw different shapes and how to update the positions of the shapes within an animation loop
